# Official product images

Put official Samsung product images here, named after their key (see `/IMAGE_MANIFEST.md`), for example:

```
galaxy-s26-ultra.webp
galaxy-z-fold8.png
galaxy-watch9.webp
galaxy-buds4-pro.webp
galaxy-tab-s11-ultra.webp
galaxy-book6-pro.webp
scene-tv.jpg          <- optional wide lifestyle background
```

Anything without a file shows a neutral empty frame (or is omitted when purely decorative).
The site never generates or substitutes a product image.
